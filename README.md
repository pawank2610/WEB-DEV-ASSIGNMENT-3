# LAB Assignment – Responsive Portfolio Website  
(Using HTML & CSS)

---

## 📝 DESCRIPTION

This project is a **personal portfolio website** built using HTML and CSS.  
It includes multiple sections such as:

- Header
- Hero Section
- About Me
- Skills
- Projects
- Contact Form
- Footer

The webpage is **fully responsive**, ensuring proper display on desktop, tablet, and mobile screen sizes.

## 📱 RESPONSIVE BEHAVIOR (BREAKPOINTS TESTED)

| Device Type | Screen Width | Behavior |
|------------|--------------|---------|
| Desktop / Laptop | > 768px | Hero section side-by-side layout |
| Mobile / Tablet | ≤ 768px | Hero section stacked vertically, centered |

✔ Responsive layout achieved using **CSS Flexbox + Media Queries**

---

## 🧪 HOW TO TEST RESPONSIVENESS

1. Open **LAB_ASSIGNMENT3.html** in a browser  
2. Press **F12** or Right-click → *Inspect*  
3. Select **Toggle Device Toolbar** (📱 icon)  
4. Test different screen sizes:
   - 1024px — Laptop
   - 768px — Tablet
   - 425px / 375px — Mobile
5. Check:
   - Navigation layout changes
   - Hero section adjusts vertically
   - Grids rearrange automatically
   - Text stays center-aligned on small screens
